**[j.owens.apps@gmail.com](mailto:j.owens.apps@gmail.com)**

Include your platform (iOS, Android, or Windows) and what you were trying to do — that's usually enough to get started.

## Common issues

**Devices can't find each other**
- Make sure both devices are on the **same WiFi network** — FileHustle only works over local WiFi, not cellular data or different networks.
- Some networks (coffee shops, hotels, some corporate/guest WiFi) enable **client isolation**, which blocks devices from seeing each other even on the same network. This is a network setting, not something FileHustle can work around — try a home WiFi network or a personal hotspot instead.
- On Windows, make sure you clicked **Allow** on the Windows Firewall prompt the first time you ran FileHustle. If you accidentally blocked it, you can fix this in Windows Security → Firewall & network protection → Allow an app through firewall.
- Give it a few seconds — discovery isn't always instant.

**A transfer won't start**
- The receiving device has to actually be running FileHustle and on-screen (or, on Android, backgrounded but not force-closed) to receive the Accept/Decline prompt.
- Every transfer requires the receiving device to accept it — nothing sends automatically.

**Where did my received file go?**
- iOS: check the share icon next to the transfer in Recent Transfers, or look under Files → On My iPhone/iPad → FileHustle.
- Android: tap **Open** next to the transfer in Recent Transfers.
- Windows: click **Open** next to the transfer in Recent Transfers.
